# billCalc

Static bill and budget calculator for GitHub Pages.

## Features

- Add income and bill rows
- Set amount, low/high range, repeat pattern, weekday, day of month, or one-time date
- Forecast low/base/high balances
- Save defaults locally in the browser

## GitHub Pages

This project is meant to be published from a GitHub Pages project site.

Expected URL:

`https://gaston1799.github.io/billCalc/`

## Local use

Open `index.html` directly in a browser, or publish the repo to GitHub Pages.
